# **App Name**: Anjuman ACM Hub

## Core Features:

- Information Presentation: Display key information about Anjuman College's ACM chapter in a clear, organized manner based on the design mockups provided, including events, team members, resources and contact details.
- Dark/Light Mode: Enable users to toggle between a light and dark color scheme to accommodate different viewing preferences and environments.
- UI Animations: Employ subtle animations and transitions to enhance the user experience and create a visually appealing and engaging website.
- Content Augmentation: AI tool to generate suitable image and text content for any section that has been updated using CMS.
- Contact Form: Implement a contact form for users to submit inquiries and feedback directly through the website.
- Membership Information: Provide clear instructions and resources for prospective members to join the ACM chapter.

## Style Guidelines:

- Primary color: Deep blue (#2E5CB3) to represent ACM's professionalism and tech focus, avoiding direct ACM colors.
- Background color: Very light gray (#F0F2F5) to ensure content readability and a clean, modern interface.
- Accent color: Soft teal (#64C5E9) to highlight key interactive elements.
- Body font: 'Inter' (sans-serif) for a modern, neutral, and highly readable text.
- Headline font: 'Space Grotesk' (sans-serif) to complement Inter with a techy and futuristic aesthetic.
- Utilize a consistent set of icons from Lucide or Font Awesome, aligning with the site's clean and modern aesthetic.
- Employ a responsive grid layout for consistent and accessible presentation of events, team members, and gallery items across devices.
- Use subtle scroll effects and transitions powered by Framer Motion to create a dynamic and engaging user experience.
